# Deployment instructions

1. Download `noir713-redesign.zip` from the ChatGPT conversation.
2. Unzip and open `noir713-redesign/index.html` locally to preview.
3. For GitHub Pages deployment, place `index.html` and the `assets/images/` folder contents into the repository root. Keep the image paths unchanged.
4. Replace the blank inquiry email recipient with a verified business address before launch.
5. Images are cropped from the supplied concept collage. The top banner is a cropped asset, not an original 4K photograph. Replace with full-resolution source images for true high-definition output.

Note: Existing production index.html on main has intentionally not been changed.
